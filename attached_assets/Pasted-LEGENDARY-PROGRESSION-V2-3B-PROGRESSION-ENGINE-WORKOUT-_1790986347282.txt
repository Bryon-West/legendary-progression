LEGENDARY PROGRESSION — V2.3B
PROGRESSION ENGINE & WORKOUT PRESCRIPTION

This is Part B of V2.3.

Do not undo V2.3A lifecycle/calendar/data-integrity fixes.
Do not reset the database.
Preserve completed workout history.

The purpose of this update is to correct how Legendary generates and evaluates workout progression.

==================================================
1. CORE PROGRESSION PHILOSOPHY
==================================================

RIR is the prescribed effort.

Reps are the performance achieved at the prescribed load/RIR.

Legendary does NOT use conventional fixed rep ranges such as 8–12.

Allowed operating range:

6–30 reps

6 and 30 are GUARDRAILS, not targets.

==================================================
2. CRITICAL COMPOUND PROGRESSION CORRECTION
==================================================

CURRENT WRONG BEHAVIOR:

Previous:
225 × 8

Next week increases load to 230 but reduces prescribed reps to 7 or 6.

That intentionally gives away the progression.

CORRECT BEHAVIOR:

When a compound exercise earns a load increase, carry the previous achieved rep benchmark forward.

Example:

Previous:
225 × 8

Next:
230 × 8

The user still trains to prescribed RIR.

The rep number is the performance benchmark we are attempting to preserve at the increased load.

DO NOT automatically subtract reps because weight increased.

==================================================
3. 5 LB = 1 REP EQUIVALENCE
==================================================

Legendary uses this heuristic to COMPARE completed performances:

5 lb ≈ 1 rep

Valid only within ±20 lb of the reference load.

Example reference:

225 × 8

Then approximately:

220 × 9
225 × 8
230 × 7
235 × 6

Therefore:

230 × 8 = PROGRESSION over 225 × 8

230 × 7 ≈ EQUIVALENT / MAINTAINED performance

230 × 6 = BELOW previous equivalent performance

RIR must also be considered.

CRITICAL:

This equivalence rule is for PERFORMANCE EVALUATION.

It is NOT a prescription rule.

Never say:

"Weight increased 5 lb, therefore subtract one prescribed rep."

2.5 lb may internally equal approximately 0.5 rep for comparison purposes, but never prescribe half reps.

Beyond ±20 lb:

Do not claim reliable equivalence.

Use completed performance/RIR to establish a new useful reference.

==================================================
4. RIR PROGRESSION
==================================================

Default loading weeks:

Week 1 = 3 RIR
Week 2 = 2 RIR
Week 3 = 1 RIR
Week 4 = 0 RIR

These defaults must be stored as actual week configuration.

If the user changes week RIR or adds/removes loading weeks, use the STORED targetRIR.

Do not derive RIR blindly from week number.

Standard four-loading-week mesocycle should persist:

==================================================
6. SET-SPECIFIC PROGRESSION
==================================================

Each working set can have its own previous performance.

Example previous workout:

Set 1 = 225 × 8
Set 2 = 225 × 7
Set 3 = 225 × 6

If the next approved load is 230:

Set 1 benchmark = 230 × 8
Set 2 benchmark = 230 × 7
Set 3 benchmark = 230 × 6

DO NOT collapse these into:

230 × 6
230 × 6
230 × 6

Do not use the lowest previous rep count as the benchmark for every set.

Preserve corresponding-set historical context whenever possible.

==================================================
7. DIFFERENT LOADS BETWEEN SETS
==================================================

Previous sets may not all use the same load.

Example:

225 × 8
225 × 7
225 × 6
205 × 9

Do not pretend these are identical performances.

Preserve the actual weight/reps/RIR of each corresponding set when establishing the next reference.

Use Legendary's equivalence logic only where valid.

==================================================
8. NEWLY ADDED WORKING SETS
==================================================

Normal loading-week progression remains:

+1 working set per exercise per new loading week

Example:

Week 1 = 3 sets
Week 2 = 4
Week 3 = 5
Week 4 = 6

A newly added set has no direct prior corresponding set.

DO NOT fabricate previous history for it.

Use the most relevant preceding working-set performance as a conservative starting reference while respecting:

- current prescribed RIR
- exercise type
- fatigue across sets
- 6-rep floor
- valid equipment increment

Internally distinguish:

DIRECT HISTORICAL SET REFERENCE

from

NEWLY ADDED SET ESTIMATE

==================================================
9. COMPOUND PROGRESSION
==================================================

Compound exercises are primarily LOAD-FIRST.

When performance supports progression:

increase load using a valid increment.

Default lb increment can include:

2.5 lb

Do not generate arbitrary weights such as:

228.37 lb

When load increases:

carry previous reps forward as the benchmark.

Do not intentionally reduce reps to "pay for" the load increase.

==================================================
10. ISOLATION PROGRESSION
==================================================

Isolation/non-compound exercises may use REP-FIRST progression.

Allow reps to increase before load where appropriate.

When performance supports increasing load, increase using valid equipment increments.

Remain within 6–30 reps.

Do not force compound and isolation exercises through identical progression rules.

==================================================
11. RIR MUST CONTROL LOAD DECISIONS
==================================================

Do not increase load simply because a workout was completed.

Compare actual RIR with prescribed RIR.

Example:

Target:
230 @ 2 RIR

Actual:
230 × 6 @ 0 RIR

The set was substantially harder than prescribed.

Do NOT automatically increase load next exposure.

Hold or conservatively adjust so the user can return toward prescribed RIR.

Example:

Target:
230 @ 2

Actual performance indicates approximately 4 RIR.

The load was easier than prescribed and may support increasing load.

Use:

- actual RIR
- target RIR
- weight
- reps
- previous performance
- exercise type
- valid equipment increment
- 6–30 guardrails

==================================================
12. SIX-REP FLOOR
==================================================

6 reps is NOT the default target.

It is the lower guardrail.

Do not automatically turn a progression into:

230 × 6

just because 6 is allowed.

If a compound is already around 6 reps and increasing load would likely create performance below the acceptable floor, HOLD load until performance supports progression.

==================================================
13. THIRTY-REP CEILING
==================================================

30 reps is the upper guardrail.

Approaching 30 reps should strongly favor increasing load when:

- equipment permits
- performance supports it
- prescribed RIR can still be respected

Do not intentionally prescribe performance beyond 30.

==================================================
14. TARGET STATUS
==================================================

For completed working sets with a valid historical reference, classify:

↑ ABOVE TARGET
✓ TARGET MET
↓ BELOW TARGET

Do NOT classify based only on raw reps.

Consider:

- weight
- reps
- actual RIR
- prescribed RIR
- valid historical reference
- Legendary equivalence heuristic where valid

Example reference:

225 × 8 at comparable RIR

Then approximately:

230 × 8 = Above Target / progression

230 × 7 = equivalent/maintained

230 × 6 = below equivalent performance

RIR differences can modify the interpretation.

Allow the status to be tapped for a short explanation.

Warmups receive no target status.

Calibration sets receive no false target status.

==================================================
15. WEEK 1 CALIBRATION
==================================================

If an exercise has no valid baseline:

Do not invent a prescription weight.

Tell user to select a weight they believe will allow approximately:

3 RIR

User records:

weight
reps
actual RIR

That establishes the baseline.

Exercises establish baselines independently.

Recent valid exercise history may survive across mesocycles.

Do not erase a valid baseline simply because a new mesocycle was created.

Baseline expiration/staleness should remain configurable rather than permanently hard-coded.

==================================================
16. NEXT-WEEK GENERATION
==================================================

Completing a workout should immediately generate/prefill the SAME training day's next weekly occurrence.

Example:

Complete Week 1 Monday
→ calculate Week 2 Monday.

Complete Week 1 Wednesday
→ calculate Week 2 Wednesday.

Do NOT wait until the future workout is opened.

By completion of Week 1, all corresponding Week 2 workouts should be generated.

Generate ALL applicable working-set rows.

==================================================
17. FUTURE WORKOUT LIMIT
==================================================

Do not fabricate progression several weeks into the future.

Trust calculated progression only when it is within one training week of the latest relevant completed exposure.

Farther future workouts can show structure but not invented load progression.

Display:

LOAD NOT CALCULATED

"This workout is more than one training week ahead of your latest completed workout."

Provide:

GO TO CURRENT WEEK

==================================================
18. DELOAD SETS
==================================================

Deload working sets:

max(1, floor(finalLoadingWeekWorkingSets / 2))

Examples:

1 → 1
2 → 1
3 → 1
4 → 2
5 → 2
6 → 3
7 → 3
8 → 4

Use the actual/programmed final loading-week working-set count.

Deload reductions must NOT be interpreted as regression.

==================================================
19. RECOVERY ADJUSTMENTS
==================================================

Temporary recovery adjustments must remain separate from progression.

If next exposure indicates poor recovery, allow:

TRAIN AS PLANNED
REDUCE LOAD
REDUCE SETS
REDUCE BOTH
SKIP EXERCISE TODAY

Reduce Load:
approximately 5%, snapped to valid increment.

Reduce Sets:
-1 working set, minimum 1.

Reduce Both:
both.

Skip:
does not count as failed progression.

Mark:

RECOVERY ADJUSTED

These changes are TODAY ONLY by default.

One recovery-adjusted workout must not automatically rewrite the strength/progression baseline.

==================================================
21. REMOVE SET
==================================================

Every working set and warmup should retain a remove/trash action.

Blank new set:
remove immediately.

Entered/completed set:
quick confirmation before removal.

Remaining working sets renumber appropriately.

Removed sets do not count toward:

performance calculations
Total Weight Lifted
progression

Completed historical data must be handled safely if edited/removed.

==================================================
22. WARMUPS
==================================================

Warmups:

- can be completed
- can be removed
- do not receive progression status
- do not establish PRs
- do not establish progression baseline
- do not count toward Total Weight Lifted
