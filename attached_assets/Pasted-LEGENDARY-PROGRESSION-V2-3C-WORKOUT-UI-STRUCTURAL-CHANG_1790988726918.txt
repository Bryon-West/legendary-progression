==================================================
1. REMOVE EXERCISE FROM CURRENT WORKOUT
==================================================

CURRENT PROBLEM:

When an exercise is removed from the current workout, it can remain visible in the exercise list.

CORRECT BEHAVIOR:

When the user selects Remove Exercise during an active workout:

- immediately remove the exercise from today's visible workout
- do not leave an empty/disabled exercise card behind
- do not require interaction with its remaining sets
- unperformed sets do not count as failed/missed
- unperformed sets do not count toward Total Weight Lifted
- preserve any sets already completed before removal
- completed sets still count toward today's workout/history/Total Weight Lifted
- record internally that the workout structure was changed

Do NOT immediately ask whether the exercise should be permanently removed from the mesocycle.

That decision happens at Finish Workout.

==================================================
2. TRACK TODAY'S STRUCTURAL CHANGES
==================================================

Track differences between the originally programmed workout and what the user actually performs.

Structural changes include:

- exercise removed
- exercise added
- exercise substituted/replaced
- exercise reordered
- working sets added
- working sets removed

Do not repeatedly interrupt the workout asking whether each change should be permanent.

Allow the user to train normally.

Maintain enough original-state information to determine the differences at Finish Workout.

Temporary RECOVERY ADJUSTED changes are NOT permanent structural changes by default.

==================================================
3. FINISH WORKOUT — ONE CHANGE SUMMARY
==================================================

When Finish Workout is pressed, if structural changes occurred, show ONE combined summary.

Example:

YOU CHANGED TODAY'S WORKOUT

Barbell Bench Press
3 → 4 working sets

Cable Fly
Moved #3 → #2

Barbell Row
Removed

Incline Dumbbell Press
Added

Then provide:

KEEP CHANGES FOR REST OF MESOCYCLE

TODAY ONLY

TODAY ONLY:

- completed workout history records exactly what happened today
- future program/template remains unchanged

KEEP CHANGES FOR REST OF MESOCYCLE:

- update applicable future UNCOMPLETED workouts
- update the future program structure
- never rewrite completed historical workouts
- normal progression continues FROM the accepted new structure

Example:

Original:
Week 2 Bench = 3 working sets

User changes today to:
4 working sets

User selects:
KEEP CHANGES

Normal +1 set progression means:

Week 3 = 5 working sets

Do NOT revert to the old template and produce 4.

==================================================
4. EXERCISE MANAGEMENT
==================================================

Exercise management should support:

MOVE UP
MOVE DOWN
SUBSTITUTE / REPLACE
REMOVE
+ ADD EXERCISE

MOVE:
changes order only.
Preserve exercise history/baseline.

SUBSTITUTE:
replace exercise going forward if user later chooses Keep Changes.
Old exercise history remains.
Replacement uses its own valid baseline/history or calibration.

REMOVE:
removes from today's visible workout immediately.
Future removal depends on Finish Workout choice.

ADD:
adds exercise to today's workout.
Future addition depends on Finish Workout choice.

Do not destroy historical exercise records when changing today's structure.

5. UNIFIED WORKOUT-DAY UI
==================================================

RULE:

CALENDAR CHOOSES THE WORKOUT.
THE WORKOUT SCREEN STAYS THE SAME.

Opening ANY scheduled workout from Calendar should use the same primary workout-day component/layout used for Today.

Do not maintain a separate simplified Calendar-workout UI.

CURRENT WORKOUT:
- fully interactive
- Complete Set
- Edit
- Add/Remove/Move/Substitute as appropriate

PAST COMPLETED WORKOUT:
- same exercise-card/set layout
- populated with actual completed values
- clearly marked COMPLETED
- read-only by default
- if completed-workout editing exists, require an explicit Edit Completed Workout action

UPCOMING CALCULATED WORKOUT:
- same workout layout
- show generated prescription
- clearly mark UPCOMING

FAR-FUTURE WORKOUT:
- same workout structure
- do not fabricate progression values
- show LOAD NOT CALCULATED where appropriate

DELOAD:
- same workout component
- clearly label DELOAD
- use deload set prescriptions

REST DAY:
- simple REST state is acceptable

==================================================
11. WHAT COUNTS TOWARD PRs
==================================================

Only COMPLETED WORKING SETS qualify.

Exclude:

- warmups
- incomplete sets
- skipped exercises
- unperformed/deleted sets
- planned prescriptions that were never performed

Deleting an old mesocycle must NOT delete completed PR history.

==================================================
12. PR TYPES
==================================================

Do not define PR as only:

"heaviest weight ever used"

Legendary should preserve useful distinctions.

At minimum support enough data/UI to distinguish:

A. HEAVIEST LOAD

Example:
275 lb × 3

B. BEST PERFORMANCE / LEGENDARY PR

A completed performance that exceeds the user's previous comparable performance using Legendary's progression logic.

Example:

Previous:
225 × 8

New:
230 × 8

This is progression/new performance record.

Where comparison is appropriate, V2.3B's existing rules remain authoritative:

5 lb ≈ 1 rep within ±20 lb

but ONLY for evaluating completed performances.

Do not alter prescriptions.

RIR remains important context when comparing performances.

Do not let V2.3C change the V2.3B progression engine.

==================================================

==================================================
16. FINISH WORKOUT FLOW
==================================================

Finish Workout should follow a coherent sequence.

Recommended flow:

1. Validate/save completed workout.
2. Resolve any required post-exercise feedback that has not yet been answered.
3. If structural changes occurred, show the ONE combined change summary.
4. User chooses Today Only or Keep Changes.
5. Persist historical workout exactly as performed.
6. Apply future structural changes only if Keep Changes was selected.
7. Generate/update next corresponding weekly prescription using V2.3B.
8. Show workout summary.
9. Close active workout state.
10. Return/advance appropriately.

Do not leave completed workout active after Finish Workout.
