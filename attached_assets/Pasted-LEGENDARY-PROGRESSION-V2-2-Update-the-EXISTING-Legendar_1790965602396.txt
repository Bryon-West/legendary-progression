==================================================
2. CORE PROGRESSION PHILOSOPHY
==================================================

Refactor Legendary Progression around this principle:

RIR IS THE PRIMARY EFFORT PRESCRIPTION.

Do NOT use conventional fixed bodybuilding rep ranges such as:

6–10
8–12
10–15

as the main progression mechanism.

The broad working-set boundaries are:

MINIMUM = 6 reps
MAXIMUM = 30 reps

6–30 is a GUARDRAIL, not a target rep range.

Reps are primarily an observed outcome of:

- load
- prescribed RIR
- individual performance

A reduction in reps is NOT automatically regression if:
- load increased
- prescribed RIR changed
- equivalent performance improved

==================================================
3. DEFAULT WEEKLY RIR
==================================================

Default loading progression:

Week 1 = 3 RIR
Week 2 = 2 RIR
Week 3 = 1 RIR
Week 4 = 0 RIR
Final Week = Deload

However:

- loading weeks can be added
- loading weeks can be removed
- each loading week's RIR is configurable
- do not hard-code exactly four loading weeks
- Deload remains the final recovery week

==================================================
4. EXERCISE CALIBRATION
==================================================

If an exercise has no valid recent baseline:

DO NOT invent a working weight.

Instead tell the user to:

"Choose a weight you believe you can perform while stopping at approximately 3 RIR."

Use the week's prescribed RIR if Week 1 has been customized.

The completed:

- weight
- reps
- actual RIR

establishes the exercise baseline.

Each exercise has its OWN baseline.

Do not transfer a baseline between different exercises.

Recent valid exercise history may carry into a new mesocycle.

Support configurable baseline staleness/expiration.

Do not permanently trust very old performance data.

==================================================
5. COMPOUND PROGRESSION
==================================================

COMPOUND EXERCISES USE LOAD-FIRST PROGRESSION.

Example:

Week 1:
225 x 8 @ 3 RIR

Week 2 may prescribe:
227.5 lb @ 2 RIR

The user performs however many reps naturally occur while stopping near 2 RIR.

If they get:

227.5 x 7 @ 2 RIR

that is NOT automatically worse than:

225 x 8 @ 3 RIR.

Do not force the user to regain the old rep number before progressing.

The primary compound progression variables are:

1. prescribed RIR
2. load
3. actual RIR
4. resulting reps
5. previous performance

==================================================
6. ISOLATION / NON-COMPOUND PROGRESSION
==================================================

Isolation/non-compound movements may use REP-FIRST progression when appropriate.

This is because the next available weight increment may represent a large percentage increase.

Allow reps to increase before load when appropriate.

When performance supports the next equipment increment:
increase load.

Still obey:

6 minimum reps
30 maximum reps

Do not introduce arbitrary smaller target ranges inside 6–30.

==================================================
8. LOAD / REP EQUIVALENCE MODEL
==================================================

Use this explicit Legendary Progression comparison rule:

+5 lb ≈ -1 rep
-5 lb ≈ +1 rep

This relationship is trusted ONLY within:

+/-20 lb

of the reference load.

Example reference:

225 x 10

Equivalent estimate:

205 x 14
210 x 13
215 x 12
220 x 11
225 x 10
230 x 9
235 x 8
240 x 7
245 x 6

Internally:

2.5 lb may equal approximately 0.5 rep-equivalence.

NEVER prescribe/display half a repetition as something the user must perform.

If the user changes the load more than +/-20 lb from the reference:

STOP calculating equivalent reps.

Show:

"Outside prediction range. Legendary Progression can't reliably estimate the equivalent rep change at this load difference. Train to the prescribed RIR and your completed set will help establish a new reference."

11. NORMAL SET PROGRESSION
==================================================

DEFAULT NORMAL PROGRESSION:

ADD ONE WORKING SET TO EVERY PROGRAMMED EXERCISE EACH NEW LOADING WEEK.

Example starting at 2 sets:

Week 1 = 2
Week 2 = 3
Week 3 = 4
Week 4 = 5

Example starting at 3:

Week 1 = 3
Week 2 = 4
Week 3 = 5
Week 4 = 6

This is the NORMAL progression path.

Do NOT require the user to earn each additional set through multiple weeks of scoring.

Recovery management may temporarily hold/reduce this progression.

Create a configurable maximum working-set limit per exercise so set progression cannot grow infinitely.

Do not invent a universal maximum without making it configurable.

==================================================
12. DELOAD SET RULE
==================================================

Deload sets are calculated from the FINAL LOADING WEEK.

Formula:

deloadSets = max(1, floor(finalLoadingWeekSets / 2))

Examples:

1 -> 1
2 -> 1
3 -> 1
4 -> 2
5 -> 2
6 -> 3
7 -> 3
8 -> 4

For odd set counts:
round DOWN.

Deload reductions are intentional and must NOT be interpreted as regression.

==================================================

- Reps
- Actual RIR

Completed sets need:

If a completed set is intentionally edited:
- save the new values
- recalculate applicable status
- recalculate future UNCOMPLETED recommendations if necessary

Do not lose completed set data on refresh.

20. RIR OVERRIDES BLIND LOAD PROGRESSION
==================================================

Do not blindly add load every week.

Example:

Prescription:

230 lb @ 2 RIR

Actual:

230 x 6 @ 0 RIR

The user overshot the prescribed effort.

DO NOT automatically increase next week's load.

Hold or conservatively adjust the recommendation so the prescribed RIR is achievable.

Likewise, if:

230 @ 2 RIR prescribed

but actual performance shows:

230 @ 4 RIR

the load was easier than intended.

That supports increasing load.

Progression must consider:

- actual RIR
- prescribed RIR
- load
- reps
- previous performance
- valid equipment increment
- 6–30 rep guardrails

21. SIX-REP FLOOR
==================================================

For compounds:

If another load increase is reasonably expected to push performance BELOW 6 reps at prescribed RIR:

HOLD LOAD.

Do not blindly increase.

The reduction in prescribed RIR from week to week can itself provide overload.
