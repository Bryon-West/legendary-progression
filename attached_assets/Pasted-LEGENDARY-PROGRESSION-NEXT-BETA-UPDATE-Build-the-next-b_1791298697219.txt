6. PR SYSTEM — ESTIMATED 1RM
==================================================

Improve resistance-training PRs so the PRIMARY performance PR is based on
estimated one-rep max (e1RM), rather than simply the heaviest weight ever used.

Use a documented, centralized e1RM calculation.

Recommended initial formula:

Epley:

e1RM = weight × (1 + reps / 30)

Example:

225 × 8 ≈ 285 lb e1RM

230 × 5 ≈ 268 lb e1RM

Therefore 225 × 8 represents the stronger performance even though 230 is a
heavier absolute load.

IMPORTANT:

Do not use e1RM blindly for very high-rep sets where the estimate becomes
unreliable.

Choose and document a sensible qualifying rep range for e1RM PR comparison.

Do not change Legendary's existing 5 lb ≈ 1 rep progression logic.

These systems serve different purposes:

5 lb ≈ 1 rep:
WORKOUT-TO-WORKOUT PROGRESSION

e1RM:
PR / PERFORMANCE HISTORY

Preserve useful secondary records such as:

- heaviest weight lifted
- actual set that produced the e1RM
- reps
- date
- RIR when available

Existing historical sets should be eligible for calculated e1RM PRs where
sufficient valid data exists.

Do not fabricate data that was never recorded.

For non-strength metric combinations, do NOT force an e1RM concept.

Their specialized PR systems can be expanded later.
