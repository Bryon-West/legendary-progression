---
name: Progression scope
description: User-requested boundary for recommendation features in the hypertrophy tracker.
---

Keep training data ready to support progression recommendations later, but do not implement a complex progression algorithm unless the user asks for it.

**Why:** the user requested future readiness while explicitly deferring complex algorithm work.

**How to apply:** do not treat the recommendation-storage schema or workout history as permission to build progression logic before it is requested.
