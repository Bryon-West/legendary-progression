---
name: Workout substitution history
description: Preserve exercise identity and set attribution when an exercise is replaced during a workout.
---

When a movement is replaced after sets have been logged, preserve the original workout exercise and its sets; represent the replacement separately rather than rewriting the exercise attribution.

**Why:** a set must remain tied to the movement that was actually performed so history stays accurate.

**How to apply:** future substitution, history, volume, or analytics changes should respect the stored workout snapshot and include completed work on superseded movements.
